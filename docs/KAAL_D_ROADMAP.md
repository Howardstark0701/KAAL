# KAAL-D — Defence Grade Upgrade Roadmap

**Status:** Planned. Not in current build scope.  
**Based on:** KAAL v1.0 (portfolio version)

KAAL-D is the defence-grade upgrade layer built on top of KAAL.
Same codebase — additional modules for defence procurement context.

## What KAAL-D Adds

1. **Air-Gapped Deployment Package** — PyInstaller standalone executable, zero post-install internet dependency, verified for air-gapped networks.

2. **Operational Impact Translation Layer** — Each finding paired with one-sentence operational consequence for non-ML decision makers. Numbers always shown first.

3. **Defence Procurement Compliance Report** — Structured for MoD/DRDO submission. Attack surface coverage matrix, operational risk ratings, remediation verification checklist with sign-off fields.

4. **Vendor Certification Mode** — SHA-256 model fingerprint in every report. Post-remediation re-audit automation. Pass/Fail certification badge with audit ID.

5. **Extended Physical Attack Pipeline** — Print color distortion compensation, distance-optimized patches (1m / 2m / 5m / 10m), lighting robustness testing under 5 conditions.
